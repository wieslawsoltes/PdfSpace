PdfSpace is an independent, local-first PDF application built in **C# with Uno Platform and SkiaSharp**. It brings familiar Acrobat-style document tabs, tool panels, floating quick tools, page organization, comments and export into a real Uno WebAssembly application and a shared desktop host.

The browser runs the same .NET document, editing and rendering libraries as the desktop application. JavaScript handles browser file dialogs, downloads, clipboard and local storage—not the PDF editor. There is no embedded third-party web PDF viewer, no server-side document processing, and no account requirement.

> **Status: 0.1.0-alpha.1.** This is a working foundation, not complete Adobe Acrobat compatibility or a pixel-identical reproduction. PdfSpace has original branding and iconography and is not affiliated with Adobe. Read the [compatibility and export boundary](docs/compatibility.md) before using it for important documents.

## The workspace

- **Read and navigate:** open local PDFs; keep up to eight documents in tabs; continuous, single-page and two-page layouts; fit page/width; zoom, pan, page navigation, virtualized thumbnails, workspace bookmarks, selectable-text search and copy.
- **Review and annotate:** highlights, underlines, strikethrough, comments and replies, resolved review items, freehand ink, rectangles, ellipses, lines, arrows, approval stamps, check marks, and inline text. Move, resize, recolor, delete and undo changes.
- **Organize:** reorder by dragging thumbnails, rotate, duplicate, delete, insert blank pages, combine PDFs, crop the visible page, extract ranges, and split into a ZIP of single-page PDFs.
- **Fill and export:** add text, initials and drawn signatures; add watermarks or page numbers; download a visual PDF, a current-page PNG, extracted text or an editable `.pdfspace` workspace. Local recovery is debounced and saved on the device.

The included six-page **Circular futures** report is an original, searchable PDF generated by the engine. Its numbers are fictional demonstration data. It is intended for testing editing and review without uploading a private document.

### Two different save operations

| Operation | Output | Important behavior |
|---|---|---|
| **Save editable workspace** | `.pdfspace` | Retains original PDF bytes, editable annotations, comments, bookmarks and page operations. Treat this file as containing the full original document. |
| **Export PDF** | `.pdf` | Creates a new, flattened visual PDF through Skia. It is not a lossless save of the source PDF; original interactive and structural features may be lost. |

**Cropping is not redaction. A drawn signature is not a certificate-based digital signature.** OCR, protection/encryption and secure redaction are deliberately unavailable rather than simulated. Original PDF text/image content-stream editing, AcroForm/XFA, digital certificates, accessibility tagging, cloud collaboration and Office conversion are not implemented in this release.

## Reusable by design

Nine libraries are independently packable; the application is a thin host.

| Package | Responsibility | Target |
|---|---|---|
| `PdfSpace.Core` | Immutable workspace, source, page, annotation and geometry models; validated JSON format | .NET 10 |
| `PdfSpace.Layout` | Page layouts, crop/rotation transforms and viewport coordinate conversion | .NET 10 |
| `PdfSpace.Editing` | Transactional editing, bounded undo/redo, page operations and comment threads | .NET 10 |
| `PdfSpace.Documents` | PDF import, metadata, word extraction, full-text search and page-range parsing | .NET 10 |
| `PdfSpace.Skia` | Cached PDF pictures, annotation painting, PDF/PNG export and sample generation | .NET 10 |
| `PdfSpace.Controls` | Custom command buttons, icons, tabs, panels, palettes, dialogs and theme resources | Uno browser / desktop |
| `PdfSpace.Viewer` | Embeddable interactive PDF viewport and virtualized thumbnails | Uno browser / desktop |
| `PdfSpace.Storage` | File, recovery, clipboard and print contracts | .NET 10 |
| `PdfSpace.Workbench` | Multi-document shell, tools, review panels and file workflows | Uno browser / desktop |

See [embedding examples and extension points](docs/components.md). NuGet packages are produced as workflow artifacts; availability on nuget.org depends on the explicitly configured publishing workflow.

## Build and run

Install the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0), Python 3 and Node.js 22. Desktop development also needs the platform prerequisites documented by [Uno Platform](https://platform.uno/docs/articles/get-started.html).

```bash
git clone https://github.com/wieslawsoltes/PdfSpace.git
cd PdfSpace
python3 scripts/fetch-assets.py
dotnet workload install wasm-tools

# Native document/rendering checks. Linux requires Skia's native runtime dependencies.
dotnet run --project tests/PdfSpace.Tests -c Release

# Desktop host; only evaluate desktop target frameworks.
dotnet run --project src/PdfSpace.App -f net10.0-desktop -p:PdfSpaceDesktopOnly=true

# Publish the actual Uno browser application.
dotnet publish src/PdfSpace.App -f net10.0-browserwasm -c Release \
  -o artifacts/publish -p:WasmShellWebAppBasePath=/PdfSpace/
python3 scripts/collect-site.py artifacts/publish artifacts/site
python3 scripts/serve-site.py --directory artifacts/site --port 4173
```

Open `http://127.0.0.1:4173/PdfSpace/`. The font-fetch script retrieves the OFL-licensed Noto Sans asset from its upstream repository. Font binaries are not committed.

### Browser acceptance tests

After publishing, generate the engine fixtures and run the tests against the local server:

```bash
dotnet run --project tests/PdfSpace.Tests -c Release
mkdir -p artifacts/fixtures
cp artifacts/engine/sample.pdf artifacts/fixtures/sample.pdf
npm install --ignore-scripts
npx playwright install chromium
npm run test:browser
```

Tests use real mouse, keyboard, file-picker and download interactions with the Uno app. An opt-in `?test=1` diagnostic view exposes read-only state and control geometry; it does not provide a document-mutation shortcut. Screenshots, traces and JUnit reports are retained by CI.

## Delivery and maintenance

**Build** validates the native engine, publishes Uno WebAssembly, exercises the browser and produces package/source artifacts. **Desktop** compiles the shared host on Windows, macOS and Linux. **Pages** deploys only a successful main-branch build and verifies both its commit identity and the public app. **Release** rebuilds and packages a version tag; NuGet publishing is optional and requires `NUGET_API_KEY`.
